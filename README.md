Gym Membership System is a Java-based desktop application built using Swing GUI. It allows gym staff to add, search, and remove members with a clean dark-themed interface. The project demonstrates all five core OOP concepts — Class & Object, Encapsulation, Inheritance, Polymorphism, and Abstraction — through a Member base class and a PremiumMember child class. Premium members can be assigned a personal trainer, while Basic members follow a standard plan. All data is managed in-memory using ArrayList, and the interface provides real-time status updates and input validation.
